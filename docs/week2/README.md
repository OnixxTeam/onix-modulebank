## Машиночитаемые контракты

Схема карты процесса и примеры лежат в репозитории задания
(`moduledev-week-2-workflow-task/08_program_and_contracts/contracts/course-1/`). В рабочий каталог
контрактов `contracts/course-1/` схему карты переносит тикет 02 — там она становится входом сборки и
